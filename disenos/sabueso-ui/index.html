Sabueso · entrega UI

Índice de la entrega

Dirección "Rastro Pleno": café + canela + crema, Anton + IBM Plex Sans. HTML + CSS estáticos, sin frameworks, sin estilos inline (compatible con CSP). Todo comparte styles.css con tokens al inicio. Los correos son la excepción obligada (tablas + inline, máx 600px, sin webfonts).

Páginas

  • p1-landing — visitante anónimo: hero, datos reales, buscador, muro con adelanto
  • p1-landing-pt — misma página en portugués (Sabujo, editais brasileños)
  • p1-landing-logueado — buscador directo + paginación del embudo (C9)
  • p1-estados-vacios — sin resultados / cobertura parcial con aviso C10
  • p2-detalle — detalle con urgencia y fuente verificada
  • p3-registro — conversión + casillas multi-ámbito (C11)
  • p4-login — con flash de error
  • p5-recuperar · p6-reset
  • p7-mi-perfil — checklist C5 + las 3 variantes de estado premium
  • p8-premium — un plan, un botón, nota honesta de cobertura
  • p9-baja — baja de alertas
  • p10-cobertura — semáforo por país (C8) + manifiesto
  • p11-errores — 404, 500 y enlace vencido

Correos

  • e1-alerta — fondos nuevos, orden local → global
  • e2-recordatorio — cierres próximos
  • e3-verificacion · e4-recuperar — un botón cada uno

Notas para integración

  • Marca: símbolo fijo (sabueso olfateando, rastro = degradé local→global) + palabra que cambia con el idioma. FundHound para dominio e internacional.
  • Semáforo de cobertura: forma + etiqueta de texto, nunca solo color (círculo lleno / rombo / anillo).
  • Cifras 423 / 23 / 19 / 67 fuentes son de muestra: inyectar valores reales.
  • Campos conservados: email, password, ambitos[] (multi), pais, region, comuna, alertas.
  • Clases clave: .franja--local…--global, .estado--*, .pill-urgente, .luz--verde/amarilla/roja.
  • Toggle ES/PT: .idioma en el nav, con aria-current en el activo.
